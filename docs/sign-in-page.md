# 工作台入口设计说明

状态：设计已确认，待页面实施。最后核对：2026-11-23。

本文规定登录页与链接处理页的目标体验。文中的“当前实现”来自当前工作区源码；“目标设计”用于后续页面改造，不表示已经实现或通过浏览器验收。本轮仅更新本文档。

## 1. 定位与已确认决策

入口是私人工作空间的门厅，让用户认出这里、理解暂时停留的原因，然后顺利进入工作台。页面低频出现，主要服务新浏览器接入和凭证失效后的再次进入。情绪目标是“回到自己的空间”：熟悉、温和、安静、可信。

宣传页独立承担产品介绍。入口不增加功能推介、作者展示区、项目外链或营销口号；个人风格通过一致的排版、视觉识别与交互细节体现。

| 决策 | 确定方案 |
| --- | --- |
| 视觉关系 | 共享工作台主题、字体和组件，入口通过布局与细节增加特色 |
| 构图 | 开放式居中，默认不使用包住全部内容的大卡片 |
| 视觉识别 | 复用现有 Codex 图标与 Codex Web 产品名 |
| 背景 | 当前主题底色，加极淡的静态柔光 |
| 动效 | 轻柔入场与状态过渡，待机静止，成功后及时进入 |
| 文案 | 温和直白，优先解释当前任务 |
| 语言 | 浏览器语言为中文时显示简体中文，其他语言显示英文 |
| 已保存连接 | 突出“连接”，测试、退出会话和移除放入更多菜单 |
| 新浏览器指引 | 默认展示简短步骤，详细方法按需展开 |
| 覆盖范围 | 登录页与链接处理页，包括加载、处理中和错误状态 |

本次目标设计不覆盖宣传页、工作台启动画面或设置页改版，不改变认证协议、设备信任、持久化和运行时拓扑。不引入新的字体、图形资产或 UI/动效依赖。

### 2.2 已有行为

| 场景 | 当前实现 |
| --- | --- |
| 本地入口 | hostname 为 localhost 时显示本地 Passkey；本地与远程 WebAuthn origins/RP IDs 隔离 |
| 远程入口 | 从浏览器读取 connection profiles，展示连接名称、上次连接时间及操作 |
| 连接已有 profile | 优先使用已保存 session；未认证时在身份绑定的已知连接上尝试远程 Passkey |
| 测试连接 | 检查连接链路与当前授权/session 状态，不触发 Passkey 或设备登记 |
| 新浏览器 | 通过 Owner 签发的一次性登录链接接入；链接可以表现为 URL 或 QR，已登录浏览器复用设备身份 |
| 链接处理 | `/app/enroll?ref=…` 自动兑换链接；首次登记设备，重复登录复用设备身份，保存连接和 session，然后进入工作台 |
| 登录页带链接参数 | 远程登录页的 `ref` 分支提供“继续”操作，跳转到链接处理页 |
| 退出会话 | 清除所选连接在此浏览器中保存的 session，保留连接资料 |
| 移除连接 | 尝试通过现有 session 撤销设备；即使无法联系工作台，也会清理此浏览器的连接资料与 secrets |
| 会话失效返回 | 失效处理清理受影响的 session 并回到 `/login`，没有向登录页传递可直接用于标题的具体失效原因 |

当前登录页主要使用英文，辅助操作并列显示。链接处理页使用独立卡片样式。连接列表缺少独立的读取中展示；无 session 时现有说明统一指向新登录链接，与连接流程可能继续使用远程 Passkey 的能力不完全一致。这些是目标设计需要解决的差异。

### 2.3 不改变的产品约束

- 产品是单 Owner 工作台。浏览器可以保存多个连接记录，不把列表扩展为多 Owner 节点管理产品。
- 新浏览器需要一次性登录链接建立设备信任。跨设备同步的 Passkey 不替代首次设备加入。
- 本地登录仍使用本地 Passkey；远程页不增加本地/远程模式开关。
- QR 是登录链接的载体，可由设备系统扫码后打开链接；入口不增加浏览器内摄像头、图片上传、全局拖放或粘贴解码。
- Owner code、fingerprint、恢复码、手工 token 输入和普通登录 QR 不进入入口 UI。
- 不根据页面可达、上次连接时间或本地 session 存在与否推断工作台实时在线。

## 3. 目标视觉与布局

### 3.1 主题与识别

复用 ThemeProvider 当前解析的主题，尊重此浏览器已有的主题偏好；新浏览器沿用现有默认与系统模式解析。入口不另设一套深浅色切换或固定的黑白配色，不新增主题偏好存储。

使用现有 CodexLogo 与“Codex Web”，图标采用当前主题文字色。标识只承担识别作用，不作为登录按钮，也不表现未经证实的在线或加密状态。

背景使用当前主题画布色；内容附近叠加单层、低对比度的静态径向柔光，颜色取自现有主题语义色。柔光不影响文本对比度；无噪点、网格、纹理、玻璃面板、光标追踪或持续变化的光场。

### 3.2 内容层级与尺寸基准

全页只有一个主内容区，依次展示：图标与产品名、情境标题、一句说明、操作区、必要帮助。标题与说明居中；连接项、操作反馈和步骤正文左对齐。

| 元素 | 默认设计基准 |
| --- | --- |
| 内容宽度 | 最大 28rem；窄屏占据扣除页边距后的可用宽度 |
| 页面留白 | 水平至少 1rem、垂直至少 2rem；短内容垂直居中，内容较长或视口较矮时自然滚动 |
| 图标与产品名 | 图标 2.5rem，产品名 0.875rem；图标不抢占标题层级 |
| 标题 | 1.5rem，semibold，使用现有字体 |
| 正文与操作 | 正文 0.875rem；按钮沿用现有组件规范，主要点击区域至少 44px 高 |
| 纵向间距 | 标识与标题区间隔 1.5rem，标题与说明间隔 0.5rem，说明与操作区间隔 1.5rem |
| 次要信息 | 使用现有 muted 文本色；辅助文字保持可读，不通过极低透明度弱化 |

内容不能靠绝对定位锁定在视口中心。长连接名称、中英文换行、展开帮助、200% 缩放及移动端横屏时，标题、操作和反馈均应可访问。

### 3.3 连接项与更多菜单

一个连接也使用连接项呈现，不自动替用户选择或尝试连接。多个连接按现有列表顺序逐项展示，不引入新的排序或默认连接持久化。

每项包含连接名称、已有的上次连接时间、主按钮“连接”和更多按钮。使用轻量表面或细边界组织连接项，不增加包围整页的大卡片。无名称时使用本地化的“已保存的连接”。长名称视觉截断时，完整名称仍可通过无障碍名称或标题提示获取。

更多菜单按“测试连接、退出此连接的会话、从此浏览器移除连接”排列，最后一项使用现有 destructive 表达。按钮的可访问名称包含对应连接名称。退出仅作用于所选连接；移除不能承诺远程撤销一定成功。

沿用现有操作资格与串行处理约束：未配对记录不能连接，无 session 时退出不可用，操作进行中避免重复提交。无 session 本身不意味着设备信任失效，也不能成为禁止尝试远程 Passkey 的理由。菜单仅调整操作组织，不新增确认流程或改变清理语义。

### 3.4 动效与无障碍

入场使用一次约 180ms 的淡入，可伴随最多 4px 的轻微位移；状态变化采用约 120–180ms 的淡入淡出，不重播整页入场。加载图标仅在真实操作进行中显示，待机时页面静止。

不使用磁吸按钮、缩放悬停、错误震动、背景失焦或长时间编排。认证成功后立即执行现有导航，不增加最短播放时长、成功页停留或再次确认。

启用 `prefers-reduced-motion` 时取消装饰性入场、位移及旋转，用即时状态和文字表达进度。保留语义化按钮、可见 focus、菜单键盘操作和帮助展开语义；不设置全局 Enter/Space 登录监听，不自动触发 Passkey，不抢占系统认证弹窗焦点。

加载与操作反馈使用 `role="status"` / 合适的 live region；错误使用 `role="alert"`，不只通过颜色传达。图标与文字重复含义时作为装饰隐藏。

## 4. 目标状态与交互

### 4.1 登录与链接状态

| 情境 | 页面标题 | 说明与内容 | 主操作及反馈 |
| --- | --- | --- | --- |
| 本地待验证 | 打开你的工作台 | 使用此本地入口的 Passkey 继续；保留按需展开的帮助 | 使用 Passkey 继续 |
| 本地认证中 | 保持原标题 | 原位置显示“正在验证身份…” | 禁止重复操作，等候真实认证结果 |
| 远程连接读取中 | 打开你的工作台 | “正在读取已保存的连接…” | 暂不显示空列表或首次接入指引 |
| 远程读取失败 | 打开你的工作台 | 显示读取失败与重试操作；不当作没有连接 | 重试读取 |
| 远程已有连接 | 打开你的工作台 | 说明选择已保存的连接，展示连接列表 | 每项“连接”，更多菜单承载辅助操作 |
| 远程连接中 | 保持原标题 | 对应连接项显示“正在连接…” | 连接按钮显示忙碌状态，保留其余内容 |
| 远程需要 Passkey | 保持原标题 | 对应连接项显示“请完成身份验证” | 仅在连接流程确定需要认证时调用 Passkey |
| 远程没有连接 | 将此浏览器连接到工作台 | 默认展示下述两步指引 | 无虚假的“立即连接”按钮；提供详细帮助展开项 |
| 登录页携带链接 | 登录此浏览器 | 说明链接将登录此浏览器并保存连接 | 继续；沿用现有跳转进入链接处理页 |
| 链接处理中 | 正在登录 | “完成后会自动打开工作台。” | 真实处理状态，不显示虚构的分段握手进度 |
| 链接成功 | 不新增停留状态 | 设备与连接保存完成 | 按现有导航及时进入工作台 |
| 链接失败 | 暂时无法登录 | 显示可确认的原因与下一步 | 临时故障可重试；失效链接引导重新获取，并提供返回入口 |

“回到自己的空间”由视觉连续性和明确说明体现，不把“欢迎回来”作为所有场景的通用标题。当前没有可靠来源的失效原因不得从 URL、session 缺失或本地标记猜测；文案保持中性。

### 4.2 新浏览器的默认指引

默认直接展示两步，不要求用户先发现隐藏操作：

1. 在已登录设备的“设置 → Connection → Sign-in link”中创建登录链接；没有可用的已登录设备时，在运行 Codex Web 的电脑上使用 CLI 获取登录链接。
2. 在此浏览器打开登录链接，或使用设备系统扫描登录二维码后在目标浏览器打开。

接着说明：“登录链接仅可使用一次，五分钟内有效。请只打开你自己生成或确认来源的链接。”

“查看详细步骤”展开后补充：在连接设置点击“Create sign-in link”，通过“Copy link”把链接发送到目标设备；确认在希望登录的浏览器中打开；所有远程设备均不可用时回到运行 Codex Web 的电脑操作。收起和展开不离开当前页面。

这里引用当前设置页实际英文标签，避免让用户寻找尚未存在的中文菜单。英文版本同样引用这些标签。不在本说明中编写未经核对的 CLI 命令，也不新增链接输入框、图片选择器或网页扫码器。

### 4.3 错误与恢复

错误就近显示：连接操作显示在对应连接项下方，读取失败显示在列表区域，本地认证和链接失败显示在各自操作区。重新执行该操作时清除对应旧反馈；不自动清除用户还未读完的错误，不将同一错误重复播报。

| 已确认的情形 | 恢复方式与表达约束 |
| --- | --- |
| 已保存连接没有 session | 允许现有连接流程按需尝试远程 Passkey；提示“连接时可能需要再次验证身份”，不直接要求新登录链接 |
| 可确认的 session 过期或失效 | 提示重新验证后继续；不宣称工作区、聊天内容或设备绑定已删除 |
| 明确取消的认证 | 保留当前页面和连接，提示“验证未完成，你可以再试一次”；不做破坏性清理 |
| 浏览器返回 NotAllowedError | 可能是取消、超时或环境限制；使用中性提示，不无条件吞掉错误或认定用户主动取消 |
| 网络中断或超时 | 提供重试；未确认前不宣称运行 Codex Web 的电脑离线，不自动要求重新登录 |
| 缺少远程 Passkey | 按现有认证错误说明，从已登录设备配置远程 Passkey，或通过新登录链接再次登录；不伪造未认证注册入口 |
| 缺少本地 Passkey | 引导到已登录设备的连接设置，按现有本地注册票据流程配置；不把远程登录链接写成本地 Passkey 的直接替代 |
| 已确认设备撤销、信任绑定失效或记录不可用 | 说明需要新的登录链接；不允许忽略身份不匹配继续连接 |
| 链接已确认无效、过期、已使用或被取消 | 引导获取新的登录链接；不把重复尝试同一失效链接作为主操作 |
| 链接错误原因不明确 | 保留现有已知错误信息，提供手动重试与返回入口；不推断设备已成功加入 |

沿用现有错误呈现边界，已知错误使用本地化提示；未知 message/details 作为文本呈现，不解释 HTML，不为本次设计新增错误遥测。无法从现有错误信息区分的原因保持合并表达，不为细分文案扩展协议。

本地已保存的连接名称和时间可以继续显示，但不从未认证服务端新增读取主机名、IP、任务、路径或工作区内容。入口不展示 session token、设备密钥、Owner public key 原文或链接 reference。
